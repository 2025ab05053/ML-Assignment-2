\# Breast Cancer Prediction using Machine Learning



\## Project Overview

This project predicts whether a tumor is \*\*Malignant (Cancerous)\*\* or \*\*Benign (Non-Cancerous)\*\* using multiple Machine Learning models.



A Streamlit web application allows users to upload datasets and evaluate predictions interactively.



---



\## Dataset

Breast Cancer Wisconsin Diagnostic Dataset



Target:

\- Malignant = 1

\- Benign = 0



---



\## Models Implemented

\- Logistic Regression

\- Decision Tree

\- KNN

\- Naive Bayes

\- Random Forest

\- XGBoost



---



\## Performance Metrics

\- Accuracy

\- Precision

\- Recall

\- F1 Score

\- AUC

\- MCC

\- Confusion Matrix



---



\## How to Run Locally



1\. Install requirements

pip install -r requirements.txt



2\. Train models

python train\_models.py



3\. Run Streamlit App

streamlit run app.py
